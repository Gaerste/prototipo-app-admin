# Prototipo de app administrativa

Prototipo clicable de una app administrativa para un restaurante: dinero, efectivo, fiscal, recursos humanos, calendario y permisos por persona.

**Todos los datos son inventados.** No guarda nada: cada cambio se pierde al recargar.

Ábrelo aquí: la página principal de este repositorio en GitHub Pages. Usa «Ver como» arriba para ver la app como cada persona y los botones Teléfono, iPad y Computadora para cambiar el formato.
